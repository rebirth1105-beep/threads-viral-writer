# 스레드 터진 글 생성기 (Claude 스킬)

스레드 글 2,232개 중 반응이 터진 302개를 분석해 만든 **공식 12개**로,
소재만 넣으면 바로 올릴 수 있는 스레드 글 초안 3개를 써 주는 Claude 스킬입니다.

## 📥 다운로드

👉 **[threads-viral-writer.zip 내려받기](https://github.com/rebirth1105-beep/threads-viral-writer/raw/main/threads-viral-writer.zip)**

## 설치

### claude.ai (웹·앱)
1. 설정 → 기능(Capabilities) → 스킬
2. 「스킬 업로드」 → 받은 zip 파일을 그대로 올리기

### Claude Code
1. zip 압축 풀기
2. `threads-viral-writer` 폴더를 아래 위치에 넣기
   - Windows: `C:\Users\내이름\.claude\skills\`
   - Mac: `~/.claude/skills/`
3. Claude Code를 다시 켜기

## 사용법

새 채팅에서 이렇게 보내면 됩니다.

```
스레드 글 써줘: 오늘 고객이 이런 질문을 했는데…
```

- 공식이 다른 초안 3개가 나와요
- "2번 더 짧게", "존댓말로", "댓글 많이 달리게"처럼 말하면 다시 써 줘요
- 처음에 "내 계정은 ○○ 하는 계정이고, 독자는 ○○들이라고 불러"라고 알려 주면 더 내 글처럼 나와요
- 숫자·경력은 [실제 숫자]처럼 비워서 나와요. 꼭 진짜 숫자로 채워서 올려 주세요
